*   Compatibility with Node 22 and later: stack trace patching and source maps now work correctly, and the new `with { type: 'json' }` import attributes syntax is supported alongside `assert`.
*   Numeric literals now support a capital `E` in scientific notation, and method calls on numbers with underscores such as `1_000.toString()` now compile correctly.
*   Performance improvements to the `flatten` helper (no longer recursive), `checkShebangLine` and the number-matching regular expressions.
*   Documentation fixes: code snippets now run correctly again, and a hover line-height shift was fixed.
*   Continuous integration now tests Node 16 through 26.
